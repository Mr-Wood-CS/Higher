# Software Implementation

!!! info "Higher course requirement"

    You must be able to **describe, exemplify, implement, read and explain** the
    structures, constructs and algorithms in this section using a procedural
    high-level language.

This section contains the implementation knowledge introduced or extended at
Higher. It assumes that you can already use National 5 constructs such as
variables, basic data types, selection, loops and ordinary 1D arrays.

## Suggested Learning Journey

Work through the lessons in this order. Each stage introduces ideas needed by
the lessons that follow.

1. **[Sub-programs](4.1-sub-programs.md)** — divide a program into reusable
   procedures and functions.
2. **[Sub-program tasks](4.1.1-sub-programs-tasks.md)** — practise modularising
   familiar National 5 programs.
3. **[Parameter passing](4.2-parameter-passing.md)** — move data into and out of
   sub-programs.
4. **[Scope of variables](4.3-scope-of-variables.md)** — distinguish local and
   global variables.
5. **[Pre-defined functions](4.4-pre-defined-functions.md)** — use the required
   substring, character-code, integer-conversion and modulus operations.
6. **[Parallel 1D arrays](4.5-parallel-1d-arrays.md)** — connect related values
   using a shared index.
7. **[Records](4.6-records.md)** — combine fields of different data types.
8. **[Arrays of records](4.7-arrays-of-records.md)** — store and process several
   records.
9. **[Sequential text files](4.8-file-handling-txt.md)** — create, read, write
   and close persistent text data.
10. **[Sequential CSV files](4.9-file-handling-csv.md)** — process structured
    rows and fields.
11. **[Linear search](4.10-linear-search.md)** — locate a target in a 1D array
    or array of records.
12. **[Find minimum and maximum](4.11-finding-minimum-and-maximum.md)** — track
    an extreme value while traversing a collection.
13. **[Count occurrences](4.12-count-occurrences.md)** — count values or records
    that satisfy a condition.

The final three lessons apply the structures, loops and indexing developed in
the earlier lessons.

## What Is Prerequisite Knowledge?

Input/output, assignment, arithmetic, string concatenation, Boolean logic,
selection, fixed and conditional loops, and basic 1D-array traversal remain
necessary programming knowledge. They are inherited from National 5 rather
than new Higher implementation outcomes, so they are used throughout these
pages instead of being repeated as separate Higher topics.
