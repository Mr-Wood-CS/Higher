# Scope of Variables

!!! info "What you need to know"

    You must be able to describe, exemplify and implement the scope of
    **local** and **global** variables.

The **scope** of a variable is the part of a program in which that variable can
be accessed.

## Local Variables

A local variable is created inside a sub-program and can only be used there.

```python linenums="1"
def calculate_total(price, quantity):
    total = price * quantity
    return total

order_total = calculate_total(3.50, 4)
print(order_total)
```

`price`, `quantity` and `total` are local to `calculate_total`. The main
program cannot access them directly. `order_total` belongs to the main program.

## Global Variables

A global variable is created outside all sub-programs and is available across
the program.

```python linenums="1"
vat_rate = 0.20

def add_vat(price):
    final_price = price * (1 + vat_rate)
    return final_price
```

`vat_rate` is global; `price` and `final_price` are local.

Although a function can read a global variable, passing required values as
parameters usually makes the module easier to test, reuse and maintain.

!!! warning

    A local variable can have the same name as a global variable. The local
    version is a separate variable and hides the global one inside that
    sub-program.
