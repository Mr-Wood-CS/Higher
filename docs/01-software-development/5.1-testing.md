# Testing

!!! info "What You Need to Know"

    For Higher Software Design and Development, you must be able to:

    - create and use a **comprehensive final test plan** to check the **functional requirements**
    - identify **syntax**, **execution**, and **logic** errors
    - explain and give examples of **dry runs**, **trace tables/tools**, **breakpoints**, and **watchpoints**

Testing means checking that a program does what it is supposed to do.

For example, a program might run without crashing but still give the wrong answer. Testing helps you spot this before someone relies on the result.

The key question is: **“Does the program do everything it is supposed to do?”**

## Testing and Debugging

**Testing** means checking for mistakes. **Debugging** means finding out what caused a mistake and fixing it.

| Activity | Example |
|---|---|
| **Testing** | Enter a mark of `50` and check that the program displays `Pass`. |
| **Debugging** | Find that the program uses `mark > 50` when it should use `mark >= 50`. |

Once you fix a mistake, repeat the test. Check some other values too, in case your change has caused a different problem.
