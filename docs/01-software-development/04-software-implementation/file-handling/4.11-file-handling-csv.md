# File Handling: CSV Files

!!! info "What you need to know"

    You must be able to describe, exemplify and implement opening, creating,
    reading, writing and closing sequential CSV files.

CSV means **comma-separated values**. A CSV file is a text file that stores
data in rows. Each row represents a record, with commas separating its fields.
In this example, each row contains a pupil's name, age and registration class:

```csv
Peter,17,R1
Laura,16,R1
Marie,16,R2
```

These examples have no header row, so the first row contains pupil data.
Python's `csv` module handles the separators and any quoting needed, such as
when a field contains a comma. Use it rather than splitting each line manually.

## Creating and Writing a CSV File

```python linenums="1"
import csv

file = open("pupils.csv", "w", newline="")
writer = csv.writer(file)
writer.writerow(["Peter", 17, "R1"])
writer.writerow(["Laura", 16, "R1"])
writer.writerow(["Marie", 16, "R2"])
file.close()
```

`csv.writer()` creates a writer for the open file. `writerow()` writes the
values in a list as one CSV row, converting numbers to text automatically.
`newline=""` lets the `csv` module handle line endings correctly and prevents
extra blank lines on some systems.

As with other text files, `"w"` creates the file if needed and removes any
existing contents. Use `"a"` to add rows at the end instead. `close()` finishes
writing any buffered data and releases the file's resources.

## Reading Sequentially

```python linenums="1"
import csv

file = open("pupils.csv", "r", newline="")
reader = csv.reader(file)

for row in reader:
    name = row[0]
    age = int(row[1])
    registration_class = row[2]
    print(name, age, registration_class)

file.close()
```

`csv.reader()` reads each row as a list of strings. The loop processes the
rows in order until it reaches the end of the file. List indexes start at zero,
so `row[0]` is the name, `row[1]` is the age and `row[2]` is the registration
class.

Convert a value when another data type is needed, as shown by `int(row[1])`.
This example assumes every row contains the three expected fields and a valid
whole number for the age. Opening a file with `"r"` requires it to already exist.

For decimal values such as prices, use `float()` instead of `int()`. Floating-point
calculations can produce small rounding differences. To display a total to two
decimal places, use `print(f"Total: {total:.2f}")`.

## Connecting Rows to Records

To keep the data for later processing, create a record from each row and add
it to a list. This complete reading example uses the record structure from
the arrays of records lesson:

```python linenums="1"
import csv
from dataclasses import dataclass

@dataclass
class Pupil:
    name: str = ""
    age: int = 0
    registration_class: str = ""

pupils = []
file = open("pupils.csv", "r", newline="")
reader = csv.reader(file)

for row in reader:
    pupil = Pupil(row[0], int(row[1]), row[2])
    pupils.append(pupil)

file.close()

for pupil in pupils:
    print(pupil.name, pupil.age, pupil.registration_class)
```
