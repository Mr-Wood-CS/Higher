Complete the lessons on text files and CSV files before starting these tasks.

These tasks bring together sequential file handling, data type conversion,
arrays and sub-programs. You will read competition results from files, process
the data and save the results so they are available after the program stops.

For each task, create and test the completed program in Python. Take a screenshot

## Task 1: Competition Scores in a Text File

A club stores competition scores in a text file, with one whole-number score
on each line. It needs a program to find the highest score and save the result.

### Set Up the Input File

Use a text editor to create `scores.txt` containing:

```text
55
72
64
```

Save the file in your program's current working folder. Do not add a heading
or blank lines. You may assume the file contains at least one valid score.

### Program Requirements

Create a modular Python program that:

1. opens `scores.txt` for reading
2. reads every score into an array of integers
3. closes the file
4. calculates the highest score
5. displays the highest score with a suitable label
6. creates `result.txt` and writes the labelled result on one line
7. closes the output file.

Use the following sub-programs, passing data between them using parameters
and return values:

| Sub-program | Purpose |
|---|---|
| `read_scores(filename)` | Open the input file, read its lines into an array of integers, close the file and return the array. |
| `find_highest(scores)` | Find and return the highest value in the array. You may use Python's `max()` function. |
| `display_result(highest)` | Display the labelled highest score. |
| `write_result(filename, highest)` | Open the output file in write mode, write the labelled highest score and close the file. |

Your main program should call these sub-programs in the correct order. Use
write mode for `result.txt` so that each run replaces the previous result.
Remember that `write()` requires a string.

### Test Your Program

For the supplied data, both the displayed output and `result.txt` should contain:

```text
Highest score: 72
```

Replace the contents of `scores.txt` for each test below, placing each score
on its own line. Run the program again and check both the screen output and
the output file.

| Scores in file, in order | Expected screen output and file contents |
|---|---|
| `55`, `72`, `64` | `Highest score: 72` |
| `90`, `45`, `60` | `Highest score: 90` |
| `12`, `30`, `85` | `Highest score: 85` |
| `48` | `Highest score: 48` |

## Task 2: Named Results in a CSV File

The club now wants to store each player's name alongside their score. Create
a new version of your program that reads CSV data and saves the winner's
details to another CSV file.

### Set Up the Input File

Use a text editor to create `players.csv` in your program's current working
folder containing:

```csv
Aisha,55
Lewis,72
Marie,64
```

The file has no header row. Each row contains a name followed by a whole-number
score. You may assume there is at least one row and every row contains valid
data.

### Program Requirements

Create a modular Python program that:

1. defines a `Player` record with a string field named `name` and an integer
   field named `score`
2. opens `players.csv` for reading, using `newline=""`
3. uses `csv.reader()` to read the rows sequentially
4. converts each score to an integer and stores each player in an array of
   records
5. closes the input file
6. finds the player with the highest score; if players share the highest
   score, selects the first of those players in the file
7. displays the winning player's name and score with suitable labels
8. creates `winner.csv` using write mode and `newline=""`
9. uses `csv.writer()` to write the winning player's name and score as one row,
   without a header, then closes the output file.

Use separate sub-programs to read and return the player records, find and
return the winning record, display the winner and write the output file.
Pass the required data using parameters and return values.

!!! tip "Finding the winning record"

    Start by treating the first player record as the winner. Compare each
    remaining player's score with the current winner's score. Replace the
    winning record only when a strictly higher score is found. This keeps the
    first winner when scores are tied.

### Test Your Program

For the supplied data, the displayed output should be:

```text
Winner: Lewis
Score: 72
```

The file `winner.csv` should contain one row:

```csv
Lewis,72
```

Replace the contents of `players.csv` for each test below, placing each
name-and-score pair on its own row. Check the displayed winner and open
`winner.csv` in a text editor to check the saved row.

| Rows in file, in order | Expected winner | Expected score | Expected row in `winner.csv` |
|---|---|---:|---|
| `Aisha,55`; `Lewis,72`; `Marie,64` | Lewis | 72 | `Lewis,72` |
| `Aisha,90`; `Lewis,72`; `Marie,64` | Aisha | 90 | `Aisha,90` |
| `Aisha,55`; `Lewis,72`; `Marie,95` | Marie | 95 | `Marie,95` |
| `Aisha,72`; `Lewis,72`; `Marie,64` | Aisha | 72 | `Aisha,72` |
| `Aisha,55` | Aisha | 55 | `Aisha,55` |
