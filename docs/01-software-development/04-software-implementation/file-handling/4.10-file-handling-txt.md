# File Handling: Text Files

!!! info "What you need to know"

    You must be able to describe, exemplify and implement opening, creating,
    reading, writing and closing sequential text files.

A file stores data so that it is available after a program stops. A **text
file** stores data as characters. When reading a file **sequentially**, a
program processes its contents in order, from the beginning to the end.

## File Modes

| Mode | Purpose | Important effect |
|---|---|---|
| `"r"` | Read | The file must already exist. |
| `"w"` | Create and write | Existing contents are replaced. |
| `"a"` | Append | New data is added at the end; the file is created if it does not exist. |

The examples below use filenames without a folder path, so Python looks for
or creates the files in the program's current working folder.

## Creating and Writing

```python linenums="1"
file = open("scores.txt", "w")
file.write("55\n")
file.write("72\n")
file.write("64\n")
file.close()
```

`open()` opens the file and returns a file object, stored here in `file`.
Opening with `"w"` creates `scores.txt` if it does not already exist.
`write()` writes a string to the file. It does not add a newline automatically,
so `\n` is included to put each score on a separate line.

`close()` finishes writing any buffered data and releases the file's resources.
Always close a file when the program has finished using it.

!!! warning "Write mode"

    Opening an existing file with `"w"` removes its previous contents.

## Appending Data

To add another score without removing the existing scores, use append mode:

```python linenums="1"
file = open("scores.txt", "a")
file.write("81\n")
file.close()
```

## Reading a Whole File

```python linenums="1"
file = open("scores.txt", "r")
contents = file.read()
file.close()
print(contents)
```

`read()` reads all the remaining contents into one string, including newline
characters. The string is still available after the file is closed.

## Reading One Line at a Time

```python linenums="1"
file = open("scores.txt", "r")

for line in file:
    score = int(line.strip())
    print(score)

file.close()
```

The loop reads each line in order until it reaches the end of the file.
`strip()` removes whitespace from both ends of the line, including its newline
character. `int()` converts the remaining text into an integer so that it can
be used in calculations. This example assumes each line contains a whole number.

When writing a number to a text file, convert it to a string first, for example
`file.write(str(score) + "\n")`.
