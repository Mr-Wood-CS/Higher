# Parallel 1D Arrays

!!! info "What you need to know"

    You must be able to describe, exemplify and implement **parallel 1D
    arrays**.

## Related Data in Separate Arrays

A one-dimensional (1D) array stores a sequence of values accessed using a
single index. In a set of **parallel arrays**, values at the same index in
each array describe the same item or person. The arrays have the same number
of elements, with corresponding values kept in matching positions.

In this lesson, Python **lists** are used to implement 1D arrays. Lists can
grow using `append()`; fixed-size arrays in other languages may require a
different approach. Each list here stores one type of data, but different
parallel lists can store different types, such as names and integer marks.

```python
pupil_names = ["Peter", "Laura", "Marie"]
pupil_marks = [20, 21, 23]
```

The arrays are parallel because:

- `pupil_names[0]` and `pupil_marks[0]` both describe Peter
- `pupil_names[1]` and `pupil_marks[1]` both describe Laura
- `pupil_names[2]` and `pupil_marks[2]` both describe Marie

The index connects the related values. Python indexes start at `0`, so index
`2` refers to the third element. Python does not automatically maintain the
relationship between separate lists: the programmer must preserve it.

| Index | `pupil_names` | `pupil_marks` |
|---:|---|---:|
| 0 | Peter | 20 |
| 1 | Laura | 21 |
| 2 | Marie | 23 |

## Accessing Corresponding Values

Use the same index with every parallel array:

```python linenums="1"
pupil_names = ["Peter", "Laura", "Marie"]
pupil_marks = [20, 21, 23]

index = 2
print(pupil_names[index], "scored", pupil_marks[index])
```

This displays `Marie scored 23`. Using different indexes would combine
values belonging to different pupils.

## Traversing Parallel Arrays

A loop can process every pupil while keeping the arrays aligned:

```python linenums="1"
pupil_names = ["Peter", "Laura", "Marie"]
pupil_marks = [20, 21, 23]

for index in range(len(pupil_names)):
    print(pupil_names[index], "scored", pupil_marks[index])
```

`len(pupil_names)` is `3`, so `range(len(pupil_names))` produces indexes `0`,
`1` and `2`. The stopping value, `3`, is excluded.

The program uses the length of one array because the parallel arrays have
matching lengths. If `pupil_marks` is shorter, the loop raises an `IndexError`
when it reaches a missing mark. If it is longer, the extra marks are not
processed. Equal lengths alone are not enough: the values must also correspond
at every index.

## Adding Related Data

When adding a new pupil, append their name and mark to the corresponding
arrays. This standalone example starts with empty lists and adds one pupil:

```python linenums="1"
pupil_names = []
pupil_marks = []

name = input("Enter pupil name: ")
mark = int(input("Enter pupil mark: "))

pupil_names.append(name)
pupil_marks.append(mark)
```

Both values are added at index `0`, so their relationship is preserved.
Appending another pupil's name and mark to these lists would place both new
values at index `1`. Do not reset the lists to `[]` between pupils, as that
would discard the existing data.

This example assumes the user enters a whole-number mark. `input()` returns
text, and `int()` converts it to an integer; input such as `twenty` or `20.5`
would raise a `ValueError`.

## Updating Corresponding Values

Use the index of the pupil whose value you want to change. Updating their
mark does not require changing their name:

```python linenums="1"
pupil_names = ["Peter", "Laura", "Marie"]
pupil_marks = [20, 21, 23]

pupil_marks[1] = 24
print(pupil_names[1], "scored", pupil_marks[1])
```

Index `1` represents Laura in both arrays, so the program changes Laura's mark
and displays `Laura scored 24`.

## Strengths and Risks

Parallel arrays are straightforward when a problem already uses 1D arrays, but
their indexes must remain synchronised:

- When adding an item, insert all its related values at the same index in
  their respective arrays.
- When removing an item, remove its values at the same index from every array.
- When reordering items, move corresponding values together. Sorting each
  array independently does **not** preserve the relationship. For example,
  sorting the original names alphabetically gives Laura, Marie, Peter, but
  sorting the marks numerically gives 20, 21, 23. This would incorrectly pair
  Laura with 20 instead of 21.

Records provide another way to group related values. They are introduced in
the next lesson.
