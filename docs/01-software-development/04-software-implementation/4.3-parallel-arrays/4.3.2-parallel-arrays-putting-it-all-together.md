## Task 1: Club Attendance

A school club stores its members' names and the number of sessions they have attended in two parallel arrays.

| Index | Member name | Sessions attended |
|---:|---|---:|
| 0 | Aisha | 6 |
| 1 | Ben | 3 |
| 2 | Cara | 5 |
| 3 | Dylan | 0 |

Create two parallel arrays called `member_names` and `sessions_attended` using the data in the table.

Display each member's name and the number of sessions they have attended, with one member on each line.

Display the names and attendance figures of members who have attended five or more sessions.

(a) Add a screenshot of your code and code output to your workbook.

(b) A programmer uses `member_names[0]` with `sessions_attended[1]`.
Which name and attendance number would this display? Explain why this is incorrect.

## Task 2: Sponsored Walk

A teacher records the distances walked by three pupils. The teacher needs
to enter each pupil's name and distance, then correct a distance if a mistake
has been made.

| Index | Pupil name | Distance in km |
|---:|---|---:|
| 0 | Erin | 4 |
| 1 | Finn | 7 |
| 2 | Grace | 5 |

Assume all distances entered are whole numbers of 0 or more, and the teacher
chooses an index of `0`, `1` or `2` when correcting a distance.

Create two empty parallel arrays called `pupil_names` and `distances_km`.
Ask the teacher to enter a name and distance for each of the three pupils
and store these in the arrays.

Display each pupil's index, name and distance. Test your program using
the data in the table.

Ask the teacher to enter the index of the pupil whose distance needs
correcting, followed by the correct distance. Update that pupil's distance
and display all three pupils' details again.

Test your program by changing Finn's distance to 9 km. Run it again with
the original data to test changing Erin's distance to 0 km, then again to
change Grace's distance to 8 km. Check that only the chosen pupil's distance
changes each time.

(a) Add screenshots of your code and code output from each test to your workbook.

(b) Explain why adding a new pupil requires adding a value to both arrays,
but correcting a distance only changes one array.

## Task 3: Equipment Loans

A school records its equipment in three parallel arrays. For each item, it
stores the name, the total number owned and the number currently borrowed.
The number available to borrow is the total owned minus the number on loan.

| Index | Equipment name | Total owned | On loan |
|---:|---|---:|---:|
| 0 | Laptop | 12 | 9 |
| 1 | Camera | 5 | 5 |
| 2 | Microphone | 8 | 2 |
| 3 | Tripod | 4 | 0 |

Create three parallel arrays called `equipment_names`, `total_owned`
and `on_loan` using the data in the table.

Write a sub-program that takes the three arrays and displays each
equipment name with the number available to borrow. Call the sub-program
from your main program.

Add the message `None available` beside any item with zero available.

Add a projector to the arrays. The school owns 3 projectors and 1 is
on loan. Run the sub-program again and check that it includes the projector
with the correct number available.

(a) Add screenshots of your code and code output before and after adding the projector to your workbook.
