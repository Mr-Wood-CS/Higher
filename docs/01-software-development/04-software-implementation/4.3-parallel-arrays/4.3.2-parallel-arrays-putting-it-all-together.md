## Task 1: Club Attendance

A school club stores each member's name and the number of sessions they have
attended in two parallel arrays.

| Index | Member name | Sessions attended |
|---:|---|---:|
| 0 | Aisha | 6 |
| 1 | Ben | 3 |
| 2 | Cara | 5 |
| 3 | Dylan | 0 |

Write a program that:

1. creates `member_names` containing the names as strings and
   `sessions_attended` containing the attendance figures as integers, in the
   order shown
2. uses an index-controlled loop to display each name with the corresponding
   attendance figure
3. uses another loop to display only members who have attended **at least
   five sessions**, together with their attendance figures

Use these expected results to check both parts of your program:

| Part | Expected output, in order |
|---|---|
| All members | `Aisha: 6 sessions`, `Ben: 3 sessions`, `Cara: 5 sessions`, `Dylan: 0 sessions` |
| At least five sessions | `Aisha: 6 sessions`, `Cara: 5 sessions` |

Display each member on a separate line. Cara tests the boundary of exactly
five sessions; Dylan tests an attendance figure of zero.

Explain why using `member_names[0]` with `sessions_attended[1]` would give an
incorrect result, even though both indexes exist.

## Task 2: Sponsored Walk

A teacher needs to enter and correct the distances walked by three pupils.

Write a program that:

1. creates empty parallel arrays named `pupil_names` and `distances_km`
2. repeats input three times, asking for one pupil's name and their distance
   in whole kilometres each time
3. converts each distance to an integer and appends the name and distance to
   their corresponding arrays inside the loop
4. displays each pupil's index, name and distance using the same index with
   both arrays
5. asks for the index of the pupil whose distance needs correcting, followed
   by the replacement distance
6. updates only that pupil's distance and displays the full list again

Initialise the empty arrays once, before the input loop. For this task, assume
that distances are non-negative whole numbers and that the correction index
is valid. Convert the correction index to an integer too.

Test your program by entering these pupils in order:

| Index | Pupil name | Distance (km) |
|---:|---|---:|
| 0 | Erin | 4 |
| 1 | Finn | 7 |
| 2 | Grace | 5 |

Enter correction index `1` and replacement distance `9`. The final display
should be:

```text
0: Erin - 4 km
1: Finn - 9 km
2: Grace - 5 km
```

Run the program again with the original data for each additional test:

| Correction index | Replacement distance | Expected change |
|---:|---:|---|
| 0 | 0 | Erin's distance becomes 0 km; the other distances stay unchanged |
| 2 | 8 | Grace's distance becomes 8 km; the other distances stay unchanged |

Explain why correcting a distance does not require changing the name at the
same index, but adding a new pupil requires appending to both arrays.

## Task 3: Equipment Loans

A school stores equipment names, the total number of each item it owns, and
the number currently on loan in **three** parallel arrays.

| Index | Equipment name | Total owned | On loan |
|---:|---|---:|---:|
| 0 | Laptop | 12 | 9 |
| 1 | Camera | 5 | 5 |
| 2 | Microphone | 8 | 2 |
| 3 | Tripod | 4 | 0 |

Write a modular program that:

1. creates `equipment_names`, `total_owned` and `on_loan` using the data above;
   store names as strings and quantities as integers
2. passes all three arrays as parameters to a display sub-program
3. loops through the arrays in that sub-program and calculates the number
   available for each item using `total_owned[index] - on_loan[index]`
4. displays each equipment name with its number available
5. displays `None available` beside any item with zero available

Expected output:

```text
Laptop: 3 available
Camera: 0 available - None available
Microphone: 6 available
Tripod: 4 available
```

Calculate availability from the arrays; do not hard-code the results. The
camera tests an item with all units on loan, and the tripod tests an item
with no units on loan.

Add `Projector`, with `3` owned and `1` on loan, to the ends of the respective
arrays. Run the program again. It should display `Projector: 2 available`
after the original four items without changing the loop's stopping value
manually. Use the length of an array to control the loop.
