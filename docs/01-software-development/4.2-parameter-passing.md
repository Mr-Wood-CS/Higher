# Parameter Passing

!!! info "What you need to know"

    You must be able to describe, exemplify and implement **parameter passing**,
    including **formal** and **actual** parameters.

A parameter carries data into or out of a sub-program. Parameter passing lets
modules share the data they need without relying on global variables.

## Formal and Actual Parameters

```python linenums="1"
def calculate_discount(price, percentage):
    discount = price * percentage / 100
    return discount

item_price = 80.00
rate = 15
amount_saved = calculate_discount(item_price, rate)
```

| Term | Example | Meaning |
|---|---|---|
| Formal parameter | `price`, `percentage` | Placeholder named in the sub-program definition |
| Actual parameter (argument) | `item_price`, `rate` | Value or variable supplied when the sub-program is called |

When the call runs, the value in `item_price` is passed to `price`, and the
value in `rate` is passed to `percentage`.

## Inputs and Outputs

In Python, values are normally passed **in** through parameters and passed
**out** with `return`.

```python linenums="1"
def find_total(price, quantity):
    total = price * quantity
    return total

order_total = find_total(4.50, 3)
```

`price` and `quantity` are inputs to the function. `total` is its output.

!!! tip "Exam language"

    Formal parameters appear in the **definition**. Actual parameters appear
    in the **call**.
