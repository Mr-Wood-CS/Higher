## Task 3: Read the Code

```python linenums="1"
def calculate_pay(hours, hourly_rate):
    pay = hours * hourly_rate
    return pay

def display_pay(employee_name, pay):
    print(employee_name, "earned £", format(pay, ".2f"))

name = "Alex"
total_pay = calculate_pay(12, 9.50)
display_pay(name, total_pay)
```

Identify:

1. the name of each sub-program
2. which sub-program is a procedure and which is a function
3. every formal parameter
4. every actual parameter
5. the input and output of `calculate_pay`
6. the local variables
7. the order in which the statements run

## Task 5: Trace Data Flow

Study this program without running it:

```python linenums="1"
def calculate_discount(price, percentage):
    saving = price * percentage / 100
    return saving

def calculate_sale_price(price, saving):
    sale_price = price - saving
    return sale_price

original_price = 80.00
discount = calculate_discount(original_price, 15)
final_price = calculate_sale_price(original_price, discount)
print("Sale price: £", format(final_price, ".2f"))
```

Create a trace table showing how the values move through the program. Then
predict its output and run it to check your answer.

## Task 6: Basketball All Star

Convert this program into a modular solution:

```python linenums="1"
basketball_player = input("Type basketball player's name: ")
season_points = int(input("Season points scored: "))
player_height = float(input("Player height: "))

if season_points > 100 and player_height >= 2.00:
    all_star = True

    all_star = False
```

## Task 7: Total Pay Program

Convert this program into a modular solution:

```python linenums="1"
employee_names = []
wages = []
total_pays = []

for index in range(5):
    employee_names.append(input("Enter employee name: "))
    wages.append(float(input("Enter employee wage: ")))
    total_pays.append(wages[index] + 50.90)

print("Employee Name\tTotal Pay")
for index in range(5):
    print(employee_names[index], "\t£", format(total_pays[index], ".2f"))
```

Your solution must:

1. use one sub-program to input employee data
2. use one sub-program to calculate total pay
3. use one sub-program to display the results
4. pass the arrays using parameters and return values
5. avoid global variables
6. include a main program that calls the modules in the correct order
