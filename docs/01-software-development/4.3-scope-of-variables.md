# Scope of Variables

!!! info "What you need to know"

    You must be able to describe, exemplify and implement the scope of
    **local** and **global** variables.

The **scope** of a variable is the part of a program where it can be accessed.
Understanding scope helps you decide what data must be passed between the main
program and its sub-programs.

## Local Variables

A local variable belongs to one sub-program and can only be accessed there.
Formal parameters are also local to their sub-program.

```python linenums="1"
def calculate_total(price, quantity):
    total = price * quantity
    return total

order_total = calculate_total(3.50, 4)
print(order_total)
```

Inside `calculate_total`, the variables `price`, `quantity` and `total` are
local. The main program cannot access them directly. `order_total` receives the
function's output and belongs to the main program.

## Global Variables

A global variable is created outside every sub-program.

```python linenums="1"
vat_rate = 0.20

def add_vat(price):
    final_price = price * (1 + vat_rate)
    return final_price
```

`vat_rate` is global, so `add_vat` can read it. The formal parameter `price`
and the variable `final_price` are local.

## Prefer Clear Data Flow

Passing required data as parameters usually makes a sub-program easier to
understand, test and reuse:

```python linenums="1"
def add_vat(price, vat_rate):
    final_price = price * (1 + vat_rate)
    return final_price

total_price = add_vat(25.00, 0.20)
```

This version states both inputs in the definition and call. It does not depend
on a hidden global value.

## Same Name, Different Variable

A local variable can have the same name as a global variable. They are separate
variables, and the local version hides the global one inside that sub-program.
Using distinct, meaningful names usually avoids confusion.

## Trace the Data

```python linenums="1"
school_name = "Riverside High"

def calculate_percentage(mark, total):
    answer = mark / total * 100
    return answer

pupil_result = calculate_percentage(36, 40)
print(school_name)
print(pupil_result)
```

| Variable | Scope |
|---|---|
| `school_name` | Global |
| `mark` | Local to `calculate_percentage` |
| `total` | Local to `calculate_percentage` |
| `answer` | Local to `calculate_percentage` |
| `pupil_result` | Main program/global scope |
