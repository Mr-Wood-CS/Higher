## Task 1: Read a Modular Program

```python linenums="1"
def calculate_pay(hours, hourly_rate):
    pay = hours * hourly_rate
    return pay

def display_pay(employee_name, pay):
    print(employee_name, "earned £", format(pay, ".2f"))

name = "Alex"
total_pay = calculate_pay(12, 9.50)
display_pay(name, total_pay)
```

Identify:

1. the procedure and the function
2. the formal parameters
3. the actual parameters
4. the inputs and output of `calculate_pay`
5. the local variables
