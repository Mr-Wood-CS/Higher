## Task 2: Top-down Design

Study this National 5 cupcake-stall program:

```python linenums="1"
large_cake_price = 2
small_cake_price = 1

large_cakes_sold = int(input("Enter number of large cupcakes sold: "))
small_cakes_sold = int(input("Enter number of small cupcakes sold: "))

large_cakes_money = large_cake_price * large_cakes_sold
small_cakes_money = small_cake_price * small_cakes_sold
total_money = large_cakes_money + small_cakes_money

overall_profit = total_money - ingredient_costs
share_each = overall_profit / 2

print("Gross total: £", total_money)
print("Costs: £", ingredient_costs)
print("Profit: £", overall_profit)
print("Share each: £", share_each)
```

Divide the algorithm into three logical sub-programs. For each one:

1. give it a meaningful name
2. describe its purpose
3. identify its inputs and outputs

## Task 4: Total Pay Program

Convert this program into a procedural solution:

```python linenums="1"
employee_names = []
wages = []
total_pays = []

for index in range(5):
    employee_names.append(input("Enter employee name: "))
    wages.append(float(input("Enter employee wage: ")))
    total_pays.append(wages[index] + 50.90)

print("Employee Name\tTotal Pay")
for index in range(5):
    print(employee_names[index], "\t£", format(total_pays[index], ".2f"))
```

Your solution must:

1. use one sub-program to input employee data
2. use one sub-program to calculate total pay
3. use one sub-program to display the results
4. pass the arrays between sub-programs using parameters and return values
5. include commentary describing the main-program calls and data flow
