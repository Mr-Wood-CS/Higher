# File Handling: Sequential CSV Files

!!! info "What you need to know"

    You must be able to describe, exemplify and implement opening, creating,
    reading, writing and closing **sequential CSV files**.

CSV means **comma-separated values**. Each line represents a record and each
comma separates fields.

```csv
Peter,17,R1
Laura,16,R1
Marie,16,R2
```

## File Modes

| Mode | Purpose | Important effect |
|---|---|---|
| `"r"` | Read an existing file | Fails if the file does not exist |
| `"w"` | Create and write a file | Replaces existing contents |
| `"a"` | Append to a file | Adds data at the end |

Append mode is useful in programs, although the Higher requirement specifically
names open, create, read, write and close.

## Create and Write

```python linenums="1"
import csv

file = open("pupils.csv", "w", newline="")
writer = csv.writer(file)
writer.writerow(["Peter", 17, "R1"])
writer.writerow(["Laura", 16, "R1"])
file.close()
```

Opening in `"w"` mode creates the file if necessary. `writerow()` writes one
record. The file is closed after use.

## Read Sequentially

```python linenums="1"
import csv

file = open("pupils.csv", "r", newline="")
reader = csv.reader(file)

for row in reader:
    name = row[0]
    age = int(row[1])
    registration_class = row[2]
    print(name, age, registration_class)

file.close()
```

The loop processes records in order from the beginning of the file to the end,
so this is sequential file handling. Values read from a CSV file are strings
and must be converted when another data type is required.

## Using `with`

Python can close a file automatically:

```python
with open("pupils.csv", "r", newline="") as file:
    reader = csv.reader(file)
    for row in reader:
        print(row)
```

Both styles demonstrate the required lifecycle; an explicit `close()` is often
shown in pseudocode and exam explanations.
