# Types of Error

### Syntax Errors

A __syntax error__ means the code breaks a rule of the programming language.

For example, Python needs a colon at the end of an `if` statement:

```python
if mark >= 50
    print("Pass")
```

The colon is missing, so Python cannot run this script. The corrected code is:

```python
if mark >= 50:
    print("Pass")
```

### Execution Errors

An __execution error__ happens while the program is running. The code follows the language's rules, but it tries to do something that cannot be carried out.

```python
scores = [12, 18, 15]
print(scores[3])
```

This list has three items, at positions `0`, `1`, and `2`. Position `3` does not exist, so Python reports an `IndexError` when it reaches that line.

Dividing a number by zero is another example of an execution error.

### Logic Errors

A __logic error__ means the program runs but does the wrong thing.

```python
if mark > 50:
    print("Pass")
else:
    print("Not yet passed")
```

The rule says that **50 or above** is a pass. This code displays `Not yet passed` for `50`, because `50 > 50` is false.

Change the condition to `mark >= 50` to include a mark of exactly `50`.

### Comparing the Three Types

| Error | Simple explanation | Example |
|---|---|---|
| **Syntax** | The code is written incorrectly. | A missing colon after `if`. |
| **Execution** | Something goes wrong when a line runs. | Trying to use a list position that does not exist. |
| **Logic** | The program runs but gives the wrong result. | Rejecting `50` as a passing mark. |

!!! note "Exam Tip"

    Explain the mistake in the question, not just the name of the error.

    For example: **“This is a logic error because a mark of 50 should pass, but the condition only accepts marks greater than 50.”**
