# Range of Positive and Negative Integers Tasks

Calculate the range of integers that can be represented using each number of bits.

For each question, calculate the range when:

- only **zero and positive integers** are stored (unsigned); and
- **negative integers, zero and positive integers** are stored (signed, using two’s complement).

Show your working and give all answers in **denary**. No binary conversions are required. State the total number of different values and the minimum and maximum values in each case.
