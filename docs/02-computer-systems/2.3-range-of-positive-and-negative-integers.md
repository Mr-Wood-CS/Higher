# Range of Positive and Negative Integers

!!! info "What you need to Know"

    **Describe and exemplify the use of binary to represent positive and negative integers using two’s complement, including the range of numbers that can be represented using a fixed number of bits.**

## How many values can we store?

Each bit can be either **0** or **1**. To find how many different values can be stored, calculate **2 to the power of the number of bits**.

For **8 bits**, this gives 2<sup>8</sup> = **256 different values**.

The **range** tells us the smallest and largest of those values. This depends on whether we are storing only zero and positive integers, or negative integers as well.

## Zero and positive integers (unsigned)

An unsigned integer can store **zero and positive integers**.

The smallest 8-bit value is ==0000 0000==. None of the place values are switched on, so this represents **0**.

### Why do we count from 0?

When converting a binary number to denary, you look only at the columns containing a **1** and add their place values. You do not normally add or count the zeros because a **0** means that its place value is switched off.

Finding a range is a different task. We are not converting the number **256** into binary. We are counting all the different bit patterns that 8 bits can make.

==0000 0000== is one valid bit pattern, and it represents **0**, so it must be included when counting the available values. The next pattern represents **1**, and the counting continues from there.

The first few values are:

* 1st value → **0**
* 2nd value → **1**
* 3rd value → **2**

Therefore, the 256th value is **255**. This means that 256 different values run from **0 to 255**:

**0, 1, 2, 3, ... 253, 254, 255**

### Using 8 bits

1. Calculate the number of different values: **2<sup>8</sup> = 256**.
2. Begin counting at **0**.
3. The 256th value is **255**, so the largest value is **256 - 1 = 255**.

The range is **0 to 255**.

This matches the place values you used at National 5. Setting every bit to 1 gives the largest unsigned value:

### Using 16 bits

The same method works with more bits:

1. Calculate the number of values: **2<sup>16</sup> = 65,536**.
2. The smallest value is **0**.
3. As the count begins at 0, subtract 1 to find the largest value: **65,536 - 1 = 65,535**.

The range is **0 to 65,535**.

## Including negative integers (signed)

Two's complement allows us to store **negative integers, zero and positive integers**.

With 8 bits, we still have **256 different values** available. Half are used for negative integers. The other half contains **zero and the positive integers**.

To find the range, first calculate the total number of values, then **halve it**.

### Using 8 bits

1. Calculate **2<sup>8</sup> = 256**.
2. Halve it: **256 ÷ 2 = 128**.
3. There are 128 negative values, ending at **-128**.
4. The other 128 values begin at **0**, so they run from **0 to 127**.

The range is **-128 to 127**.

!!! tip "Only subtract 1 on the positive side"

    After halving the total, use that same result to find each limit:

    * **Negative limit:** put a minus sign in front. Do not subtract 1.
    * **Positive limit:** begin counting at 0. A group of 128 values runs from **0 to 127**, so subtract 1 from 128.

### Using 16 bits

Follow exactly the same steps:

1. Calculate **2<sup>16</sup> = 65,536**.
2. Halve it: **65,536 ÷ 2 = 32,768**.
3. There are 32,768 negative values, ending at **-32,768**.
4. The other 32,768 values begin at **0**, so they run from **0 to 32,767**.

The range is **-32,768 to 32,767**.

## Comparing the ranges

The number of bits determines **how many different values** are available. Whether the integer is unsigned or signed determines **where the range starts and ends**.

!!! tip "Exam Tip"

    When asked to calculate a range, show your working and give the smallest and largest values in **denary**. No binary conversions are required.

    **Unsigned:** calculate the total → start at 0 → subtract 1 for the maximum.

    **Two's complement:** calculate the total → halve it → use a minus sign for the minimum and subtract 1 for the maximum.
