# Computer Architecture

Computer architecture describes the components of a computer system and how they work together to execute programs. Computers come in many forms, but they all use the same basic model: data enters through an input device, is processed, may be stored, and is presented through an output device.

![The processor, main memory and system buses](../Images/Computer_Structure_1.png)

## Input and output

An **input device** sends data or instructions into a computer system. Examples include a keyboard, microphone and camera.

An **output device** presents processed data from a computer system. Examples include a monitor, speaker and printer.

Some devices perform both roles. A touchscreen displays output and detects input, while a network interface sends and receives data.

## The processor

The **central processing unit (CPU)** executes program instructions and controls the computer's operation. It contains several important components.

| Component | Purpose |
| --- | --- |
| **Control unit (CU)** | Coordinates the processor's activities. It decodes instructions and sends control signals to other components. |
| **Arithmetic and logic unit (ALU)** | Performs calculations, comparisons and logical operations. |
| **Registers** | Very small, fast storage locations inside the processor that hold current instructions, addresses and data. |

Different registers have specific jobs. For example, the **program counter (PC)** stores the address of the next instruction, while the **instruction register (IR)** stores the instruction currently being decoded or executed.

## Main memory

**Main memory** stores the programs and data that the processor needs to access directly.

| Memory type | Description |
| --- | --- |
| **Random access memory (RAM)** | Stores programs and data currently in use. It is volatile, so its contents are lost when the power is switched off. |
| **Read-only memory (ROM)** | Stores instructions or data that should remain when power is removed, such as firmware used during start-up. It is non-volatile. |

RAM is normally much faster than secondary storage, but it is still slower than registers and cache.

## Secondary storage

**Secondary storage** keeps programs and data when the power is switched off. Examples include solid-state drives, hard disk drives and memory cards.

Storage has a much larger capacity than RAM and is non-volatile, but the processor cannot execute instructions directly from it. A program must first be loaded from storage into RAM.

## System buses

A **bus** is a collection of parallel lines used to carry signals between components.

| Bus | Purpose | Direction |
| --- | --- | --- |
| **Address bus** | Carries the address of the memory location or input/output port being accessed. | Normally from the processor to other components. |
| **Data bus** | Carries data and instructions. | Bidirectional: data can travel to or from the processor. |
| **Control bus** | Carries control signals such as read, write and timing signals. | Bidirectional: signals travel between the processor and other components. |

!!! note "Address bus and data bus"

    The address bus identifies **where** a transfer should happen. The data bus carries **what** is being transferred.

## Cache memory

**Cache** (pronounced *cash*) is a small amount of very fast memory located in or close to the processor. It stores copies of frequently or recently used instructions and data, reducing the time the processor spends waiting for RAM.

Cache is explored in more detail in [Factors Affecting System Performance](3.3-system-performance.md).
