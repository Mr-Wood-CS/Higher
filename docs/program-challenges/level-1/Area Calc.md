# Area Calc

Difficulty: Level 1

Save your file as: `Area Calc.py`

## Your Task

Write a program that calculates the area of a rectangle.

The user should enter:

- the width of the rectangle
- the length of the rectangle

Your program should multiply the width by the length and display the answer.

## Example

```text
Enter the width: 5
Enter the length: 8
The area is 40
```

## Success Criteria

- Ask the user to enter the width.
- Ask the user to enter the length.
- Store both values in variables.
- Calculate the area using `width * length`.
- Display the area clearly.

## Hint

Remember that values from `input()` are stored as text. Convert them to numbers before multiplying them.
