# Jim's Bonus Scheme

Difficulty: Level 1

Save your file as: `Jim's Bonus Scheme.py`

## Your Task

Jim is writing a program to calculate the wages of workers in a teddy bear factory.

Workers sometimes get a GBP 50 bonus if they make enough teddy bears.

Write a program that asks the user for:

- the worker's basic wage
- the number of teddy bears the worker made

If the worker made 100 or more teddy bears, add a GBP 50 bonus to their wage.

If the worker made fewer than 100 teddy bears, their wage stays the same.

## Example 1

```text
Enter the worker's basic wage: 300
How many teddy bears did they make? 120
The final wage is GBP 350
```

## Example 2

```text
Enter the worker's basic wage: 300
How many teddy bears did they make? 75
The final wage is GBP 300
```

## Success Criteria

- Ask for the worker's basic wage.
- Ask how many teddy bears the worker made.
- Use an `if` statement to check whether the worker gets the bonus.
- Add GBP 50 only when the worker made 100 or more teddy bears.
- Display the final wage clearly.
