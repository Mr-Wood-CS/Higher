# Name Change

Difficulty: Level 1

Save your file as: `Name Change.py`

## Your Task

Write a program that asks the user for their full name and then greets them.

The user might enter a name such as:

```text
Mr Reid
```

Your program should include their name in the greeting.

## Example

```text
Enter your full name: Mr Reid
Hello, Mr Reid
```

## Success Criteria

- Ask the user to enter their full name.
- Store the name in a variable.
- Use the variable in your output message.
- Display a friendly greeting.

## Hint

You can join text and a variable in a `print()` statement.
