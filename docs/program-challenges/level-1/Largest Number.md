## Your Task

A programmer has started a Python program that asks the user to enter two whole numbers.

The program should:

- compare the two numbers
- display which number is larger
- display a message if both numbers are equal

Complete the program below by filling in the gaps using the items in the box.

You will not need to use all the items. Each item should only be used once.
