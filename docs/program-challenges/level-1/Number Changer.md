# Number Changer

Difficulty: Level 1

Save your file as: `Number Changer.py`

## Your Task

Write a program that asks the user to enter four different numbers.

Your program should use the numbers to calculate four new values:

- the numbers added together
- the numbers subtracted from each other
- the numbers multiplied together
- the numbers divided by each other

Display each answer clearly so the user knows which calculation was used.

## Example

```text
Enter number 1: 12
Enter number 2: 6
Enter number 3: 3
Enter number 4: 2

Added together: 23
Subtracted: 1
Multiplied: 432
Divided: 0.3333333333333333
```

## Success Criteria

- Ask the user to enter four numbers.
- Store each number in a variable.
- Convert each input to a number.
- Calculate an addition answer.
- Calculate a subtraction answer.
- Calculate a multiplication answer.
- Calculate a division answer.
- Display all four answers clearly.

## Hint

Division can create decimal answers. Use `float()` if you want your program to accept decimal numbers.
