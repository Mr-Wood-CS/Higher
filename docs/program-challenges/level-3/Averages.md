# Averages

Difficulty: Level 3

Save your file as: `Averages.py`

## Your Task

Write a program that lets a user work out the average of a series of numbers.

The user should be able to specify how many numbers they want to enter before inputting the numbers.

Example input:

```text
4
17
21
14
11
```

Example output:

```text
15.75
```

## Check Your Program

Your program should work no matter how many numbers the user chooses to enter.
