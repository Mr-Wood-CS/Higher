# Lower Case

Difficulty: Level 3

Save your file as: `Lower Case.py`

## Your Task

Write a Python program that inputs a character and checks whether it is lowercase.

Your program should:

- get the user to enter a character and store it in a suitable variable
- determine whether the entered character is a lowercase character
- output `LOWER` if the user has entered a lowercase character
- output `NOT LOWER` if the user has entered any other character

Use meaningful variable names, correct syntax and correct indentation.

## Check Your Program

Test your program with a lowercase letter, an uppercase letter and a number.
