# Five A Day

Difficulty: Level 3

Save your file as: `Five A Day.py`

## Your Task

Design and implement a program that allows the user to enter a positive number.

The program should display all numbers divisible by 5 up to the number entered.

Example:

```text
Input: 30
Output: 5, 10, 15, 20, 25, 30
```

## Check Your Program

Your program should work for any positive number entered by the user.
