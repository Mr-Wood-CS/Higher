# Cake Maker

Difficulty: Level 3

Save your file as: `Cake Maker.py`

## Your Task

A cake recipe uses 100 grams of flour and 50 grams of sugar for every egg used in the recipe.

Write a program that asks the user how many eggs they want to use, validates the input, then calculates how much flour and sugar are needed.

Validation rules:

- the number of eggs must be positive
- the number of eggs must be at least 1
- the maximum number of eggs is 8

You should assume that the user will always enter an integer.

## Check Your Program

The user should keep being asked to re-enter the number of eggs until they enter a valid number.
