# Ice Cream!

Difficulty: Level 3

Save your file as: `Ice Cream!.py`

## Your Task

Write a program that helps an ice cream seller estimate how many ice creams they are likely to sell on a particular day.

Your algorithm should:

- ask the user to enter whether it is the weekend or a weekday
- ask the user to enter the temperature forecast in degrees Celsius
- keep asking for the temperature until the user enters a number between 20 and 45 inclusive
- calculate the number of ice creams likely to be sold
- double the estimate if it is a weekend
- output the estimated number of ice creams likely to be sold

Estimate rules:

- 100 ice creams are likely to be sold if the temperature is between 20 and 30 degrees inclusive
- 150 ice creams are likely to be sold if the temperature is between 31 and 38 degrees inclusive
- 120 ice creams are likely to be sold if the temperature is higher than 38 degrees

## Check Your Program

Your program should use validation for the temperature and should only accept values from 20 to 45 inclusive.
