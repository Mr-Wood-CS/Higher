# Darts

Difficulty: Level 3

Save your file as: `Darts.py`

## Your Task

Create a program that tells a user how many points away from 180 they are after throwing three darts.

The program must check each dart score to make sure it is valid. A single dart cannot score greater than 60.

The user will enter three integers representing each dart.

Example input:

```text
20
40
5
```

Example output:

```text
115
```

## Check Your Program

Each dart score must be checked before it is included in the total.
