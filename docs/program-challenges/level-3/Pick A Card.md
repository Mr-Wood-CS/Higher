# Pick A Card

Difficulty: Level 3

Save your file as: `Pick A Card.py`

## Your Task

A program is being developed in Python to simulate a card game.

Throughout the game, each player always has 100 cards. Each card displays a number.

Players take it in turns to swap one of their cards with another random card from a set of cards until a player has a run of five numbers in sequence within their 100 cards.

The starter code below gets a player to enter the position of a card to swap.

```python
position = int(input("Enter card position: "))
```

Extend the program. It should keep getting the user to enter the card position until they enter a card position between 1 and 100 inclusive.

Use meaningful variable names, correct syntax and correct indentation.

## Check Your Program

Test your program with values below 1, above 100 and inside the valid range.
