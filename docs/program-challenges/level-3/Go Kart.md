# Go Kart

Difficulty: Level 3

Save your file as: `Go Kart.py`

## Your Task

Write a Python program that estimates the braking distance in metres for a new model of go-kart travelling between 10 and 50 kilometres per hour.

Your program should:

- keep asking the user to enter a speed until they enter a speed between 10 and 50 inclusive
- calculate the braking distance in metres by dividing the speed by 5
- ask the user if the ground is wet
- expect the user to enter `yes` if the ground is wet
- multiply the braking distance by 1.5 if the ground is wet
- output the final calculated braking distance

Use meaningful variable names, correct syntax and correct indentation.

## Check Your Program

Your program should validate the speed before calculating the braking distance.
