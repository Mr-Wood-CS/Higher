# Times Tables

Difficulty: Level 3

Save your file as: `Times Tables.py`

## Your Task

Write a program that lists the times table from 1 to 12 for any number the user enters.

The program should ask the user for a single number.

Example input:

```text
2
```

Example output:

```text
1 x 2 = 2
2 x 2 = 4
3 x 2 = 6
4 x 2 = 8
5 x 2 = 10
6 x 2 = 12
7 x 2 = 14
8 x 2 = 16
9 x 2 = 18
10 x 2 = 20
11 x 2 = 22
12 x 2 = 24
```

## Check Your Program

The program must print all 12 lines of the times table.
