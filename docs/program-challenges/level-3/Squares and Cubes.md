# Squares and Cubes

Difficulty: Level 3

Save your file as: `Squares and Cubes.py`

## Your Task

Write a program that displays either square numbers or cube numbers.

The squared number sequence starts:

```text
1, 4, 9, 16, 25
```

The cubed number sequence starts:

```text
1, 8, 27, 64
```

Ask the user:

- how many numbers they want to display
- whether they want the squared sequence or the cubed sequence

Then display the correct sequence.

## Check Your Program

The program should use the user's choice to decide which calculation to perform.
