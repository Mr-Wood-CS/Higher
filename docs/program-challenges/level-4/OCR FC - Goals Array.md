# OCR FC - Goals Array

Difficulty: Level 4

Save your file as: `OCR FC - Goals Array.py`

## Brief

Elliott plays football for OCR FC. He wants to create a program to store the results of each football match they play and the names of the goal scorers.

The number of goals scored in each football match is held in an array called `goals`.

Example array:

```python
goals = [0, 1, 3, 0, 4, 5, 2, 0, 2, 1]
```

Elliott wants to count how many matches ended with 0 goals.

## Requirements

Convert the pseudocode algorithm into Python.

Your program should:

- loop through the `goals` array
- count how many values are `0`
- print the final count
