# Pin Checker

Difficulty: Level 4

Save your file as: `Pin Checker.py`

## Brief

Write a program that checks how strong a user's PIN number is.

The user should input their PIN number. The program should output whether it is strong. If it is not strong, the program should explain why.

PIN rules:

- the PIN must be 4 digits long
- the PIN must not be four consecutive numbers, such as `1234` or `5678`
- the PIN must not be four identical numbers, such as `0000` or `8888`

If the PIN is strong, tell the user they have a strong PIN number.

## Requirements

Your program should:

- accept the user's PIN
- check the PIN length
- reject four consecutive digits
- reject four identical digits
- explain why a weak PIN is weak
- confirm when the PIN is strong
