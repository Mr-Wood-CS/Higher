# Free Electricity!

Difficulty: Level 4

Save your file as: `Free Electricity!.py`

## Brief

Roger has switched to a new electric supplier.

He will receive free electricity one day a week. He will not pay for the day when he uses the least amount of electricity.

Write a program that:

- allows the user to input each day of the week
- allows the user to input the number of electricity units used for each day
- compares the usage values
- outputs the day that will be free of charge

## Requirements

Your program should:

- collect a usage value for each day
- keep track of the lowest usage value
- keep track of the day linked to the lowest usage value
- output the correct free day
