# How Many Cars?

Difficulty: Level 4

Save your file as: `How Many Cars?.py`

## Brief

Write a program that works out whether there are enough car seats for a trip.

The program should:

- asks the user to input how many cars are available for a trip
- asks the user to input how many people are going on the trip
- outputs `We have enough seats` if there are enough seats
- calculates how many extra cars are needed if there are not enough seats
- outputs `Another x cars are needed`, replacing `x` with the number of cars

Assume that five people can fit in each car.

## Requirements

Your program should:

- calculate the total number of available seats
- compare the available seats with the number of people
- calculate extra cars only when needed
- round up when calculating extra cars
