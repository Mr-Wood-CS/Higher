# 6th Form Admissions

Difficulty: Level 4

Save your file as: `6th Form Admissions.py`

## Brief

Write a program that calculates whether a pupil has enough GCSE points for sixth form admission.

The program should:

- asks the user to input how many GCSEs they have
- allows the user to enter a grade for each GCSE
- works out how many points they have got, where grade 9 is worth 9, grade 8 is worth 8, and so on

Output rules:

- if their score is 40 or over, output `You can go to the sixth form`
- if their score is between 35 and 39, output `A discussion is needed`
- otherwise, output `Sorry not enough points.`

## Requirements

Your program should:

- use a loop to collect all GCSE grades
- keep a running total of the score
- use selection to choose the correct final message
