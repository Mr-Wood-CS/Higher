# Email Validator

Difficulty: Level 4

Save your file as: `Email Validator.py`

## Brief

Write a program that validates a user's email address.

The user should be able to input their email address.

Example input:

```text
student1@laurustrust.org.uk
```

The program should check that the email:

- contains an `@` symbol
- does not contain any spaces

If the email is valid, output a suitable message.

Example:

```text
Your email is acceptable
```

If the email is invalid, output a message explaining what is missing or incorrect.

## Requirements

Your program should:

- ask the user to enter an email address
- check for an `@` symbol
- check that there are no spaces
- output a suitable message for valid emails
- output a useful reason for invalid emails
