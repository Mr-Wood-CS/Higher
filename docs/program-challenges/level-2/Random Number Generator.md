# Random Number Generator

Difficulty: Level 2

Save your file as: `Random Number Generator.py`

## Your Task

Write a program that generates a random whole number based on a user's chosen range.

Ask the user to input two different numbers:

- the minimum value
- the maximum value

The program should generate and output a random number between these values.

## Example

```text
Enter the minimum number: 1
Enter the maximum number: 20
Your random number is 13
```

## Success Criteria

- Import the `random` module.
- Ask the user for the minimum value.
- Ask the user for the maximum value.
- Generate a random whole number in the chosen range.
- Display the random number clearly.
