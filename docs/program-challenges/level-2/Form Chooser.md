# Form Chooser

Difficulty: Level 2

Save your file as: `Form Chooser.py`

## Your Task

Write a program that asks the user for their name and form.

The program should greet the user by name and tell them which room to go to for registration.

Forms and rooms:

| Form | Room |
| --- | --- |
| 10A | 0.12 |
| 10B | 1.23 |
| 10C | 2.34 |

Example input:

```text
Ben
10A
```

Example output:

```text
Hello Ben, please go to Room 0.12
```

## Success Criteria

- Ask the user to enter their name.
- Ask the user to enter their form.
- Use selection to choose the correct room.
- Include the user's name in the output.
- Display the correct room for the form entered.
