# New Email

Difficulty: Level 2

Save your file as: `New Email.py`

## Your Task

Write a Python program to check whether a user has entered the same email address twice.

Your program should:

- ask the user to input an email address
- ask the user to input the email address a second time
- output `Match` and the email address if the email addresses are the same
- output `Do not match` if the email addresses are not the same

## Example 1

```text
Enter your email address: pupil@example.com
Enter your email address again: pupil@example.com
Match: pupil@example.com
```

## Example 2

```text
Enter your email address: pupil@example.com
Enter your email address again: pupil2@example.com
Do not match
```

## Success Criteria

- Ask the user to enter an email address.
- Ask the user to enter the email address again.
- Compare the two inputs.
- Display `Match` and the email address when they are the same.
- Display `Do not match` when they are different.

Use meaningful variable names, correct syntax and correct indentation.
