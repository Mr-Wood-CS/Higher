# BMI Checker

Difficulty: Level 2

Save your file as: `BMI Checker.py`

## Your Task

Write a program that calculates a user's BMI and tells them whether they are underweight, normal weight or overweight.

BMI is calculated using:

```text
weight in kg / height in metres squared
```

Categories:

- underweight: less than 18.5
- normal weight: between 18.6 and 24.9
- overweight: over 25

Ask the user to input their weight in kilograms and height in metres.

Example output:

```text
Your BMI is 16.3. You are underweight.
```

## Success Criteria

- Ask the user for their weight in kilograms.
- Ask the user for their height in metres.
- Calculate BMI using the formula.
- Use selection to choose the correct category.
- Display the BMI and category clearly.

## Extension

Round the BMI to 2 decimal places.
