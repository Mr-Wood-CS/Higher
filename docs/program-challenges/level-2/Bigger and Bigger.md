# Bigger and Bigger

Difficulty: Level 2

Save your file as: `Bigger and Bigger.py`

## Your Task

Write a program that asks the user to enter three numbers.

The numbers can be entered in any order. Your program should compare them and display the largest number.

## Example

```text
Enter number 1: 12
Enter number 2: 7
Enter number 3: 19
The largest number is 19
```

## Success Criteria

- Ask the user to enter three numbers.
- Store each number in a variable.
- Convert the inputs to numbers.
- Compare the three numbers.
- Display the largest number clearly.
