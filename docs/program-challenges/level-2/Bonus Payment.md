# Bonus Payment

Difficulty: Level 2

Save your file as: `Bonus Payment.py`

## Your Task

Write a Python program that calculates an employee's bonus payment.

The bonus depends on:

- how many items the employee has sold
- how many years the employee has been employed

The program should:

- ask the user to input the number of items sold
- ask the user to input the number of years employed
- output the value of the bonus payment

Bonus rules:

- if the years of employment is less than or equal to 2 and the number of items sold is greater than 100, the bonus is the number of items sold multiplied by 2
- if the years of employment is greater than 2, the bonus is the number of items sold multiplied by 10
- otherwise, the bonus is 0

## Example

```text
Enter the number of items sold: 120
Enter the number of years employed: 2
The bonus payment is GBP 240
```

## Success Criteria

- Ask for the number of items sold.
- Ask for the number of years employed.
- Use selection to decide which bonus rule applies.
- Calculate the bonus correctly.
- Display the bonus payment clearly.

Use meaningful variable names, correct syntax and correct indentation.
