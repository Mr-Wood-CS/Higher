# Taxi Fare

Difficulty: Level 2

Save your file as: `Taxi Fare.py`

## Your Task

Write a Python program that allows a taxi company to calculate the total fare for a journey.

The program should:

- allow the user to enter the journey distance in kilometres
- allow the user to enter the number of passengers
- charge GBP 2 for every passenger, regardless of distance
- charge a further GBP 1.50 for every kilometre, regardless of how many passengers there are
- output the final taxi fare

## Example

```text
Enter the journey distance in km: 4
Enter the number of passengers: 3
The total fare is GBP 12.0
```

In this example:

- passenger cost is `3 * 2`
- distance cost is `4 * 1.5`
- total fare is `12.0`

## Success Criteria

- Ask for the journey distance.
- Ask for the number of passengers.
- Calculate the passenger cost.
- Calculate the distance cost.
- Add both costs together.
- Display the total fare clearly.

Use meaningful variable names, correct syntax and correct indentation.
