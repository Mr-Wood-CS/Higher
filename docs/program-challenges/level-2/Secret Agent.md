# Secret Agent

Difficulty: Level 2

Save your file as: `Secret Agent.py`

## Your Task

Write a program that tells secret agents where to pick up intel packages.

The program must only give the real information to the secret agent. Store the secret code `HTSSAW`, then ask the user to enter the code.

If the codes match, output a suitable message, for example:

```text
The package will be at 231 Marsden Street
```

If the codes do not match, display a fake message, for example:

```text
Nothing to see here...
```

## Success Criteria

- Store the secret code in a variable.
- Ask the user to enter a code.
- Compare the user's code with the secret code.
- Display the real message only if the code is correct.
- Display the fake message if the code is incorrect.
