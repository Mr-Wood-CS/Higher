# Password Check

Difficulty: Level 2

Save your file as: `Password Check.py`

## Your Task

Write a Python program that asks the user to enter a password and checks whether it is correct.

Your program should:

- input a password and store it in a suitable variable
- display `Welcome` if the password entered is equal to `secret`
- display `Not welcome` if the password entered is not equal to `secret`

## Example 1

```text
Enter the password: secret
Welcome
```

## Example 2

```text
Enter the password: hello
Not welcome
```

## Success Criteria

- Ask the user to enter a password.
- Store the password in a variable.
- Compare the password with `secret`.
- Display the correct message.

Use meaningful variable names, correct syntax and correct indentation.
