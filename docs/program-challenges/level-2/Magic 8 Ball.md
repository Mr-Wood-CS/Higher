# Magic 8 Ball

Difficulty: Level 2

Save your file as: `Magic 8 Ball.py`

## Your Task

Write a program that gives the user a random answer to a yes-or-no question.

The user should enter their question. The program should then give one answer from the following options:

- `Definitely`
- `Most Probably`
- `Its still unclear`
- `Not Likely`
- `No Chance`

You will need to import the `random` module.

## Example

```text
Ask a yes-or-no question: Will I win the lottery this week?
No Chance
```

## Success Criteria

- Import the `random` module.
- Ask the user to enter a yes-or-no question.
- Randomly choose one of the possible answers.
- Display the answer.

## Extension

Store all output statements in a list, then randomly choose one statement from the list.
