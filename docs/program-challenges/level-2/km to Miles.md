# km to Miles

Difficulty: Level 2

Save your file as: `km to Miles.py`

## Your Task

Write a program that can convert kilometres into miles and miles into kilometres.

Conversion facts:

- 1 km = 0.62 miles
- 1 mile = 1.6 km

The program should ask the user whether they are entering miles or kilometres, then ask for the amount.

If the user's input is not `miles` or `km`, output an error message.

## Example 1

```text
Are you entering miles or km? miles
Enter the distance: 7
That is 11.2 km
```

## Example 2

```text
Are you entering miles or km? km
Enter the distance: 10
That is 6.2 miles
```

## Success Criteria

- Ask whether the user is entering miles or kilometres.
- Ask for the distance.
- Convert miles to kilometres when needed.
- Convert kilometres to miles when needed.
- Display an error message for invalid choices.
