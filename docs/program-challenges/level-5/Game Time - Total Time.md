# Game Time - Total Time

Difficulty: Level 5

Save your file as: `Game Time - Total Time.py`

## Brief

Heath is researching how long, to the nearest minute, each student in his class spends playing computer games in one week, from Monday to Friday.

He is storing the data in a two-dimensional array.

For example, student 1, on Monday, played 30 minutes of computer games.

Heath needs to work out the average number of minutes spent playing computer games each day for the class, which contains 30 students.

## Requirements

Write an algorithm to output the average number of minutes the whole class spends playing computer games each day.

Your solution should:

- process a two-dimensional array
- calculate a separate total for each day
- divide each day total by the number of students
- output the average for each day clearly
