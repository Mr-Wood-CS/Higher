Identify:

  1. the two substrings used in the program
  2. the value assigned to department
  3. the value assigned to item_number
  4. the purpose of ord() and chr()
  5. the value assigned to remainder
  6. the exact output produced by the program

In your workbook, write your answers to questions 1–6.

Task 3

A school stores a pupil result as a single code. A code such as MIA073B contains:

  • the pupil identifier in characters 1–3
  • the mark in characters 4–6
  • the class letter in character 7

Write a program that:

  1. asks the user to enter a seven-character result code
  2. uses substrings to extract the pupil identifier, mark and class letter
  3. converts the mark from a string to an integer
  4. converts the class letter to its character code
  5. calculates the remainder when the mark is divided by 10
  6. converts the next character code back to a character using chr()
  7. displays all the calculated results with suitable labels

Test your program with the following data:

Result code Pupil identifier Mark Class code Remainder Next letter
MIA073B MIA 73 66 3 C

Run the program using the test data. In your workbook, include:

  1. a screenshot showing all of your completed code
  2. a screenshot showing the input and all five expected output values

The Username Generator

A school creates a username from a pupil's details. Write a program that:

  1. asks for the pupil's first name, surname and year number
  2. extracts the first character of the first name
  3. extracts the first four characters of the surname
  4. converts the year number to an integer
  5. uses modulus to calculate the remainder when the year number is divided by 2
  6. joins the substrings and year number to create and display a username
  7. displays the character code of the username's first character

Test the program using Aisha, Khan and 2026. The username should be AKhan2026, and the remainder should be 0.

In your workbook, include:

  1. a screenshot showing all of your completed code
  2. a screenshot showing the username, remainder and character code
