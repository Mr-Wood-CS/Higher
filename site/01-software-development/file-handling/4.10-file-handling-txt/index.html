File Handling: Text Files

What you need to know

You must be able to describe, exemplify and implement opening, creating, reading, writing and closing sequential text files.

A file keeps data after a program stops. A sequential file is processed in order, from the beginning to the end.

File Modes

Mode Purpose Important effect
"r" Read The file must already exist.
"w" Create and write Existing contents are replaced.
"a" Append New data is added at the end.

Creating and Writing

1
2
3
4
5
file = open("scores.txt", "w")
file.write("55\n")
file.write("72\n")
file.write("64\n")
file.close()

Opening with "w" creates scores.txt if required. \n starts a new line. The file is closed after the program finishes using it.

Write mode

Opening an existing file with "w" removes its previous contents.

Reading a Whole File

1
2
3
4
file = open("scores.txt", "r")
contents = file.read()
file.close()
print(contents)

Reading One Line at a Time

1
2
3
4
5
6
7
file = open("scores.txt", "r")

for line in file:
    score = int(line.strip())
    print(score)

file.close()

strip() removes the newline character and int() converts the text into an integer.

file = open("names.txt", "w")

  3. explain why \n is used
  4. write code that opens names.txt, reads it sequentially and displays both names
